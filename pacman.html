操作手册

移动　方向键或 WASD。可提前输入连续两个转向，迷宫上方的箭头显示待执行方向。反向键立即掉头。手机可点圆盘上的四向按钮，或短距离滑动迷宫来转弯。键盘和鼠标按下对应方向时，圆盘会亮起。小屏进入大城区会自动跟随角色，点「切到全图」可查看路线。

反击、补给与其他玩法

反击　大颗闪光豆能让幽灵短暂变蓝，连续吃掉它们会翻倍得分。左右隧道互通。

街区事件　蓄能潮让每颗豆充能三倍，黄金时段让豆子分数翻倍。全城警报会临时切换为追击，能量豆和定格依然有效。事件开始前 3 秒可在迷宫上方看到预告。

定格　每局带一枚定格脉冲。按 E 或点「定格」让幽灵停住 2 秒，期间可以安全穿过。再吃 35 颗豆充满。

无尽模式　分数会提高幽灵速度和追击占比。余豆低于初始数量的四分之一时，全图随机补豆，补到阈值即停。慢速、标准、快速分别每 2 秒、1 秒、0.5 秒补一颗。每新生成 50 颗豆，其中一颗是能量豆。

巢穴迷宫　外围、内环和核心的补给密度依次为 1、1.5、2 倍。进入两个巢穴的重叠区域时，两边都可能有幽灵追来。

AI 斗蛐蛐　赛前可为每位选手选择形象。进入竞技场后可以调幽灵、拖动选手和布置障碍，点「开始比赛」才计时。选中减速带或加速带后，可按住拖动连续铺设。两种速度带只影响吃豆人，速度分别减 30% 和加 30%。自动补豆每 50 颗生成一颗能量豆。被吃掉的幽灵在中央巢穴等待 3 秒再出动。虚线预告风暴区域，连续停留超过 2 秒扣一命并进入正常免伤。风暴消退后在原区域刷新可抵挡一次伤害的护盾。

任务星章　达到街区目标得一星，无损命、在标注时限内完成各加一星。同一站保留最高星数，自由选择下一站。

暂停与退出　按 P 或 Esc 暂停，对局顶部的「回大厅」可直接退出。

AI 扩展接口

在游戏加载后，通过浏览器控制台或游戏脚本后的自定义脚本调用 PacArena.registerAI。注册成功的选手会带着自己的策略出现在「扩展AI」组。

PacArena.registerAI({
  id: 'my-ai',
  name: '我的AI',
  decide(state) {
    return state.legalMoves[0];
  }
});

每次选手需要决定下一格时，decide 同步返回 up、down、left 或 right。state 提供 self、opponents、ghosts、legalMoves 和 cellAt(col,row)。坐标从 0 开始。PacArena.listAIs() 可查看已注册选手。
