# 吃豆人 · 午夜巡游

《午夜巡游》是一款像素夜城风格的网页迷宫游戏。你可以在迷宫里吃豆、躲避幽灵，找准时机用能量豆反击。也可以把迷宫交给 AI，自己当裁判，看不同策略的选手在同一张地图上争夺补给、躲避风暴。

## 开始游玩

下载仓库里的游戏 HTML 文件（`pacman.html`，部署时也可能命名为 `index.html`），直接用浏览器打开即可。游戏使用单文件 HTML、CSS 和 JavaScript，可以离线游玩。个人最高分和巡游星章保存在当前浏览器中。

| 操作 | 按键或手势 |
| --- | --- |
| 移动 | 方向键或 `WASD`。手机可点四向圆盘，或在迷宫画面上短滑 |
| 定格幽灵 | 按 `E` 或点「定格」 |
| 暂停 | `P`、`Esc` 或暂停按钮 |

## 玩法

- **经典街机与无尽模式**。选一张固定迷宫，或预览并重掷随机地图。经典街机吃光豆子即可进入下一关。无尽模式会在余豆变少时自动补豆，幽灵也会随分数提高追击强度。
- **巢穴迷宫**。在 111 × 99 格的大地图上穿过九座幽灵巢穴的巡逻范围，越靠近中心，补给越密集。
- **任务挑战**。沿 13 个站点收集晶片、捕获幽灵并争取星章。也可以挑战五站连战的霓虹远征，或在每日冲刺里用 90 秒刷新纪录。
- **训练场**。从右上角「操作手册」进入，练习转弯、能量豆反击和隧道穿行。

## AI 斗蛐蛐

最多让 **8 位 AI 选手**同场较量。可以单机试跑，也可以开大逃杀、无尽赛或争夺赛。赛前能设置初始生命、选择形象、微调选手策略，还能拖动选手改变出生点。比赛中可以调整各类幽灵数量和追击强度，在地图上铺设路障、加速带或减速带，并在右侧查看选手排名和幽灵、风暴造成的伤害。

想让自己写的 AI 参赛，可以通过 `PacArena.registerAI()` 注册 JavaScript 策略。游戏内「操作手册 → AI 扩展接口」提供了接入示例。
